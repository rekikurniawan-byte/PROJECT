## Cara pakai

1. Jalankan notebook Colab utama sampai export CSV.
2. Copy isi `colab_tambahan_multi_produk_forecast.py` ke cell paling bawah notebook Colab, lalu run.
3. Setelah file `multi_product_forecast.csv` berhasil dibuat di Google Drive, jalankan Streamlit ini.
4. Isi path:
   `/content/drive/MyDrive/output_forecasting_retail_uk`
